# Wolf Notes

月下人狼をプレイしながら、自分用に状況を整理するメモアプリです。ブラウザだけで動き、データはそのブラウザの localStorage に自動保存されます。

## できること

- **参加者の一括登録**: ゲーム画面の参加者一覧をそのまま貼り付けます
- **盤面**: 参加者ごとに生死・CO・推理（村/狼/狂/狐/？）・怪しさ（5段階）・メモを記録します
- **ログ取込**: ゲーム画面の次のログを貼り付けると自動で反映します
  - 投票結果（`名前	N票	→投票先`）→ 投票表
  - `○○は処刑されました。` → 処刑・生死
  - `○○は無残な姿で発見されました。` → 朝の襲撃・生死
  - 終了後の参加者一覧（名前・役職・勝敗）→ 実際の役職と推理の的中数
- **判定**: 占い・霊能の結果をCO者ごとの表で比較できます
- **投票**: 日ごとの投票先と、全日程の投票履歴
- **日別**: 襲撃・処刑・その日のメモ
- **メモ**: 内訳の仮定やラインなどの自由メモ
- **履歴**: 過去の試合と推理の的中数

画面幅が狭いとき（ゲーム画面の横に並べたとき）はタブで切り替え、広いときは盤面と各パネルを左右に並べて表示します。

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # ログ解析などのテスト
npm run build    # dist/ に出力
```

`main` に push すると GitHub Actions で GitHub Pages に公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。
