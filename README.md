# サブスクリプション分析ダッシュボード

モバイルアプリのサブスクリプション契約状況を可視化するダッシュボードです。

## 機能

- **KPIメトリクス表示**
  - 有効サブスクリプション数
  - 新規サブスクリプション数
  - 解約数
  - MRR（月次経常収益）
  - トライアル転換数

- **フィルタリング機能**
  - 期間: 過去7日間、30日間、90日間、1年間、全期間
  - プラットフォーム: iOS、Android、全て
  - プランタイプ: 月額、年額、全て

- **チャートビジュアライゼーション**
  - 有効サブスクリプション数の推移
  - MRRの推移
  - 新規サブスクリプション
  - 解約数
  - トライアル転換数

- **生データビューア & エクスポート機能**
  - 生データを表形式で表示
  - ページネーション機能（50件ずつ表示）
  - CSV形式でエクスポート
  - JSON形式でエクスポート
  - フィルタリングされたデータのみ表示

- **動的データ生成**
  - アプリ起動時に毎回異なるダミーデータを自動生成
  - データ再生成ボタンでいつでも新しいデータに切り替え可能
  - より高いランダム性（成長率、スパイク発生率、初期値が毎回変動）

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Recharts
- date-fns

## 特徴

- リアルタイムでフィルタリング可能
- レスポンシブデザイン
- 前期間比較による変化率表示
- リアルなダミーデータ（トレンド、スパイクを含む）
- **毎回異なるランダムデータ**: サーバー起動のたびに異なるデータパターンが生成されます
- **ワンクリックでデータ再生成**: 「データを再生成」ボタンで即座に新しいデータセットに切り替え
- **生データへの完全アクセス**: ブラウザ上でフィルタリングされたデータを確認し、CSV/JSON形式でエクスポート可能

## データの特性

生成されるダミーデータには以下の特性があります：

- **成長トレンド**: 日次成長率が0.2%〜0.5%の範囲でランダムに設定
- **曜日効果**: 週末は契約数が減少、月曜日は増加する傾向
- **ランダムスパイク**: 3%〜7%の確率で1.3倍〜3.3倍のスパイクが発生
- **初期値の変動**: 各セッションで初期アクティブサブスクリプション数が変動
- **高い変動性**: ベース値から±30%の範囲でランダムに変動

## 使い方

### データの再生成

右上の「データを再生成」ボタンをクリックすることで、いつでも新しいデータセットに切り替えることができます。これにより、異なるパターンやトレンドを確認できます。

### 生データの表示とエクスポート

1. 右上の「生データを表示」ボタンをクリック
2. モーダルウィンドウでフィルタリング済みの生データを確認
3. 「CSV出力」または「JSON出力」ボタンでデータをエクスポート
4. ページネーションで大量のデータを快適に閲覧
