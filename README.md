# サブスクリプション分析ダッシュボード

モバイルアプリのサブスクリプション契約状況を可視化するダッシュボードです。

## 機能

- **KPIメトリクス表示**
  - 有効サブスクリプション数
  - 新規サブスクリプション数
  - 解約数
  - MRR（月次経常収益）
  - トライアル転換数

- **フィルタリング機能**
  - 期間: 過去7日間、30日間、90日間、1年間、全期間
  - プラットフォーム: iOS、Android、全て
  - プランタイプ: 月額、年額、全て

- **チャートビジュアライゼーション**
  - 有効サブスクリプション数の推移
  - MRRの推移
  - 新規サブスクリプション
  - 解約数
  - トライアル転換数

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Recharts
- date-fns

## セットアップ

```bash
# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

## 特徴

- リアルタイムでフィルタリング可能
- レスポンシブデザイン
- 前期間比較による変化率表示
- リアルなダミーデータ（トレンド、スパイクを含む）
